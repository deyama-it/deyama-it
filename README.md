# でやま

元・codex全振り丸投げの駆け出しエンジニア
↓
療養しながら資格勉強＆個人開発を楽しむ人。

動物保護活動や小さな事業のITまわりを支える「出山IT事務所」を隠れ蓑にして
ゆっくり勉強したり個人開発したり猫吸ったりしてるアラフォー。
まずは「創る楽しみ」を忘れず勉学に励みながらAIフル活用していきます。
勉強会等でお会いした方々のGitHubアカウントをよくフォローしたりします。勉強させてください！

## About

- 個人開発における学習・制作の記録を発信しています
- 保護猫活動に関わり、動物保護活動のIT化にも関心があります
- GitHub、生成AI、プロンプト、アプリ開発を勉強中です
- AIに任せた作業でも、差分・意図・表示結果を自分の言葉で確認できるよう練習しています
- 「家族より大事な仕事なんてあるわけない」を大切にしています
- 千葉市生まれ千葉市育ちですが、現在は仙台市在住です
- 出山IT事務所の名ばかりの代表をしています

## Current Focus

- 「何がしたいのか」「どうなりたいのか」の内容を明確にし、言語化する練習

- GitHubをもっと扱えるようになること
- codex全振り丸投げをやめて、少しでもコマンドを打てるようになる練習
- note、Zenn、Qiita、勉強会レポートなど、学んだことを外に出す発信の継続
- 動物愛護の現場課題を、ITやAIでどう楽にできるか考えること

## Now

療養を最優先にしながら、資格勉強と個人開発を少しずつ進めています。

GitHubやCodexを使って「考えたことを形にする」練習をしつつ、学んだことや試行錯誤も残していきます。
猫たちとの時間を大切にしながら、いつか動物保護の現場で役立つものを作れるよう、楽しく続けるのが今の目標です。
